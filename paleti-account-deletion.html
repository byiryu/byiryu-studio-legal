본 안내는 Google Play 데이터 보안 정책 및 Apple App Store Connect 의 "사용자 계정 삭제 (Account Deletion)" 요구사항에 따라 제공됩니다.

PALETI 의 로그인은 byiryu studio 가 제공하는 여러 서비스(PALETI · 무한의전장 등)에서 함께 사용하는 통합 로그인 계정을 이용합니다. 앱 내 회원 탈퇴는 다음과 같이 동작합니다.

  1. PALETI 서비스 데이터가 즉시 삭제됩니다 (§2).
  2. 이어서 다른 byiryu studio 서비스에 회원님의 데이터가 남아 있는지 자동으로 확인합니다.
    • 남아 있으면 → 그 서비스를 계속 이용하실 수 있도록 통합 로그인 계정은 유지됩니다. 이 경우 계정까지 지우시려면 §3 의 전체 탈퇴를 요청해 주세요.
    • 남아 있지 않으면 → 통합 로그인 계정도 함께 삭제됩니다. 별도 요청이 필요 없습니다.

즉, PALETI 만 이용하신 경우 앱 내 회원 탈퇴만으로 계정과 데이터가 모두 삭제됩니다.

1. 회원 탈퇴 방법

방법 1 — 앱 내 탈퇴 (즉시 처리, 권장)

  1. PALETI 앱 실행 후 Google 또는 Apple 계정으로 로그인합니다.
  2. 메인 화면 우측 상단의 설정 아이콘 을 탭해 마이페이지로 진입합니다.
  3. 화면 하단 "계정" 섹션의 [회원 탈퇴] 항목을 탭합니다.
  4. 확인 dialog 의 [탈퇴] 버튼을 탭합니다.
  5. PALETI 서비스 데이터가 즉시 삭제되며, 앱은 로그인 화면으로 돌아갑니다.

본 흐름은 서버의 회원 탈퇴 API 를 호출하여 PALETI 서비스 데이터를 데이터베이스에서 즉시 영구 삭제하고, 다른 byiryu studio 서비스의 데이터가 없는 경우 통합 로그인 계정까지 함께 삭제합니다 (§3 참조).

방법 2 — 이메일 요청 (영업일 기준 7일 이내 처리)

앱 접근이 어려운 경우 (앱 삭제 후 / 디바이스 분실 등) 다음 양식으로 이메일을 보내주세요.

    • 본인 확인을 위한 추가 정보 (요청 시 안내)

이메일 수신 후 본인 확인 절차를 거쳐 영업일 기준 7일 이내에 PALETI 서비스 데이터를 삭제합니다. 통합 로그인 계정의 처리는 앱 내 탈퇴와 동일한 기준(§3)을 따릅니다.

2. 삭제되는 데이터 (즉시 삭제, 복구 불가)

회원 탈퇴 시 서버에 저장된 다음 PALETI 서비스 데이터가 즉시 영구 삭제되며 복구할 수 없습니다.

  • 사용자 프로필·환경설정
    • 선호 컬러 테마 (10종 중 선택)
    • 다크/라이트 모드 설정
    • 알림 토글 (아침 푸시·미세먼지 경보)
    • 기본 위치 (수동 선택 도시)
    • 성별 정보
  • 추천 이력 (사용자가 받은 모든 코디 추천 기록)
  • 추천 피드백 (추천 결과에 남긴 평가)
  • 생성된 추천 이미지
  • FCM 푸시 토큰 (푸시 알림 발송용 기기 식별자)

4. 익명 캐시로 일시 보관되는 데이터 (최대 7일)
